# Customer Service Training

Учебный проект Customer Service для освоения Codex и AI Agentic Workflow.

## Технологический стек

Java 21, Spring Boot 3.5.16, Maven, Spring MVC, Spring Data JPA, H2 (runtime), JUnit 5 через `spring-boot-starter-test`.

## Область действия инструкций

Перед началом работы пройди от корня репозитория до каталога каждого целевого файла, включая промежуточные каталоги. В каждом каталоге проверь `AGENTS.override.md` и `AGENTS.md`. Если есть `AGENTS.override.md`, используй его вместо `AGENTS.md` из того же каталога. При конфликте правил приоритет у файла из ближайшего к целевому файлу каталога. Совместимые правила вышестоящих каталогов продолжают действовать.

## Engineering Workflow

- Отвечай по-русски и сохраняй английскую техническую терминологию.
- Уточняй неоднозначные требования, если выбор существенно влияет на результат, совместимость или объём работы. В остальных случаях продолжай с разумным допущением и укажи его.
- Для сложной задачи до внесения изменений кратко обозначь шаги реализации и способ проверки.
- Меняй только то, что нужно для задачи. Избегай сопутствующего рефакторинга и форматирования. Согласуй расширение scope с пользователем.
- Добавляй зависимости и выполняй commit или push только с явного разрешения пользователя.
- После изменений кода проверь через `mvn -version`, что Maven использует JDK 21, затем запусти `mvn verify`.
- Самостоятельно исправляй ошибки, вызванные текущими изменениями, и повторяй проверку. Сообщай пользователю о ранее существовавших ошибках вне рамок задачи.
- Не отключай тесты и не ослабляй проверки ради успешной сборки.
- Соблюдай ограничения окружения и sandbox. Если проверка заблокирована, не обходи ограничения. Укажи, какая проверка не выполнена и почему, отдельно от дефектов кода. Сообщай об успехе только после фактического успешного выполнения проверки.
