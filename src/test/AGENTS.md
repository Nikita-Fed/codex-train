# Тесты

- Используй JUnit Jupiter. Размещай тесты в пакете тестируемого класса и называй методы по сценарию и ожидаемому результату.
- Структурируй тесты по Arrange–Act–Assert и проверяй наблюдаемое поведение. Покрывай применимые успешные, ошибочные и граничные сценарии. При исправлении дефекта добавляй или обновляй тест, воспроизводящий его.
- Используй unit-тесты для изолированной логики, Spring test slices для отдельных слоёв и `@SpringBootTest` для проверки сборки контекста или взаимодействия компонентов.
- Делай тесты независимыми от порядка запуска и внешних сервисов. Для тестов persistence используй изолированные данные H2. В fixtures используй только синтетические данные.
