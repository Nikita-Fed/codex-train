# Production-код

- Валидацию входных данных выполняй на границе приложения. Используй отдельные DTO для внешнего API и возвращай клиенту понятные ошибки без внутренних деталей.
- Размещай бизнес-правила в сервисах или доменных классах, обработку HTTP в контроллерах, доступ к данным в repositories. Задавай границы транзакций на уровне сервисной операции.
- Используй constructor injection и `final` для обязательных зависимостей. Если Lombok уже подключён, используй его аннотации для шаблонного кода и `@RequiredArgsConstructor` для внедрения зависимостей. В текущем проекте пиши конструкторы явно.
- Проверяй права доступа на сервере перед чтением или изменением защищённых данных. Для пользовательских значений используй параметры запросов вместо конкатенации SQL или JPQL.
- Обрабатывай только персональные данные, необходимые для операции, и исключай их из логов и диагностических сообщений. Получай секреты из внешней конфигурации и не записывай их в исходники, логи или ответы API.
