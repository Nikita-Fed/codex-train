## Изоляция контекста

Старая сессия сохранила все пять контрольных фактов. Четыре предварительных архитектурных решения предусматривали `UUID` для идентификаторов клиентов, Soft Delete, Optimistic Locking и уникальность email без учёта регистра. Пятым фактом было кодовое название **Project Blue Falcon**. Новая сессия без передачи контекста эти сведения не восстановила.

## Context Compaction

Во время эксперимента команда `/compact` была доступна в Codex в IntelliJ IDEA. После сжатия проверочный запрос подтвердил сохранение всех пяти контрольных фактов. Замеры непосредственно до и после сжатия отсутствуют, поэтому точный коэффициент сжатия неизвестен.

## Session Handoff

Для передачи рабочего контекста создали [HANDOFF.md](../HANDOFF.md). Новая сессия восстановила архитектурные решения и их предварительный статус, состояние проекта, открытые вопросы, блокеры и дальнейшие действия. Кодовое название в кратком отчёте не прозвучало. На отдельный вопрос новая сессия назвала **Project Blue Falcon**.

Context Compaction сокращает историю в контексте текущей сессии и сохраняет сведения для продолжения работы в ней. При Session Handoff агент в новой сессии читает подготовленную рабочую сводку и продолжает задачу с зафиксированного состояния.

## Рекомендуемая структура Handoff

| Поле | Что записать |
| --- | --- |
| Git branch | Текущую ветку. |
| Commit SHA | SHA коммита `HEAD` на момент передачи. |
| Working Tree | Результат `git status --short` или отметку о чистом рабочем дереве. При наличии изменений пояснить, какие относятся к задаче. |
| Acceptance Criteria | Условия, по которым можно проверить завершение задачи. |
| Статус задачи | Цель, выполненную и оставшуюся работу, принятые и предварительные решения. |
| Открытые вопросы | Что ещё нужно согласовать и какие блокеры мешают продолжению. |
| Результаты проверок | Выполненные команды, фактические результаты и причины пропущенных или заблокированных проверок. |
| Следующие разрешённые действия | Что можно сделать сразу и для каких действий требуется отдельное разрешение. |
